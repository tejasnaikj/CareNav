# CareNav

CareNav is an Android application project.  
Follow the steps below to set up and run the app on your system.

---

## Prerequisites

Before running this project, make sure you have the following installed:

- **Android Studio**
- A physical Android device
- USB debugging enabled

---

## Steps to Run the App

1. **Install Android Studio**
   - Download and install Android Studio from the official website.

2. **Open the Project**
   - Launch Android Studio.
   - Click on **Open** and select this project folder.

3. **Sync the Project**
   - Let Android Studio download required dependencies.
   - Wait until **Gradle Sync** completes successfully.

4. **Build the Project**
   - Click on **Build → Make Project**.
   - Ensure there are no build errors.

5. **Connect a Device**
   - Connect a physical Android device using USB  
     **OR**
   - Start an Android Emulator from Android Studio.

6. **Run the App**
   - Click the **Run ▶️ button** in Android Studio.
   - Select your connected device or emulator.
   - The app will be launched on the device.

---

## Notes

- Make sure your device has **USB debugging enabled**.
- If you face build issues, try **Invalidate Caches & Restart** in Android Studio.
- Internet connection is required during the first build for dependency downloads.
